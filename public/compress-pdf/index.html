Honest compression, in your browser

In-browser compression has real limits, so we’re straight about it. Light rewrites the PDF’s structure and strips metadata without changing the pages — text stays selectable, and savings are usually modest. Balanced and Strong re-render each page as an optimized image, which shrinks image-heavy and scanned PDFs a lot, but makes text non-selectable. We always show the real before-and-after size, and if a file is already well optimized we say so rather than handing back something that isn’t actually smaller.

Frequently asked questions

Is my PDF uploaded?

No. Everything runs locally in your browser. The PDF is never sent to RedactLocal.

Which level should I use?

Use Light when you need to keep selectable, searchable text. Use Balanced for a good size-vs-quality default on scanned or image-heavy PDFs, and Strong when the smallest possible file matters more than fine detail.

Why didn’t my file get smaller?

If a PDF is already well optimized, lossless Light compression can’t do much. We’ll tell you honestly and suggest trying Balanced or Strong, which reduce image quality for larger savings.
