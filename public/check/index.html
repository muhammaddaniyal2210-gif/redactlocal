How this works

A PDF stores text separately from anything drawn on top of it. Covering a name with a black rectangle adds a drawing instruction — it doesn’t delete the characters underneath, which stay in the file at known positions. This reads that text layer back the same way a copy-paste, a converter, or pdftotext would.

Permanent redaction removes the underlying content. Some PDF tools remove selected text and graphics while preserving the rest of the document. RedactLocal uses a flattened export: marked areas are burned into page images, and the original text layer is not included — all in your browser, with the file never leaving your device.
